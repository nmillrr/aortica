# Archive

Planning material from the build-out of Aortica, kept for history. None of it
describes the current state of the code or the released models — for that,
see the repository README and `releases/`.

| File | What it was |
|------|-------------|
| `PRD.md`, `PRD-2.md` | Product requirements for phases 0–4 (user stories) |
| `project-plan.md` | Original product plan and roadmap |
| `deep-research-report.md`, `ai-ecg-landscape-report.md` | Market and literature landscape reports |
| `progress.txt` | Log written by the autonomous agent that implemented the PRD stories |
| `agent-workflows/` | Prompts for that agent (formerly `.agents/workflows/`) |

Much of what the PRDs list as delivered — for example 72 trained outputs,
differential privacy and secure aggregation in federated training, PyPI and
Docker Hub distribution — was scaffolded in code but is not trained, wired in
or published. Do not cite these documents as a description of capabilities.
